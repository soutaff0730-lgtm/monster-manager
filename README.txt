# モンスト管理 スマホ版

このフォルダはスマホのSafari/Chromeで使えるPWA（Webアプリ）として公開できます。

## 重要
iPhoneでは、ZIPを「ファイル」アプリから直接開くだけではPWAとして正常に動かない場合があります。
GitHub PagesなどのHTTPS対応の静的サイトにこのフォルダの中身を公開してください。

## iPhone
1. Safariで公開したページを開く
2. 「共有」→「ホーム画面に追加」
3. ホーム画面の「モンスト管理」から起動

## PC・スマホ間のデータ移動
アプリ内の「データを書き出す」「データを読み込む」「共有する」を使ってJSONを移動できます。
このアプリ自体はサーバーに個人データを送信せず、ブラウザのローカル保存を使います。

## GitHub Pagesで公開する場合
このZIPを解凍し、`index.html` が公開サイトの一番上の階層になるように配置してください。
